# Прогнозирование стоимости квартир в Москве

Учебный проект по машинному обучению: построение и сравнение регрессионных моделей для предсказания стоимости квартир в Москве по характеристикам недвижимости.

## Задача

Предсказать стоимость квартиры на основе её площади, количества комнат, расположения, близости к центру, характеристик дома и других признаков. Сравнить линейные модели, деревья решений и градиентный бустинг.

## Данные и подготовка

- Датасет содержит около 20 тысяч объектов недвижимости и признаки, описывающие квартиры и их расположение.
- Проведена очистка от выбросов: удалены 202 объекта с экстремально высокой стоимостью.
- Для линейных моделей использовано масштабирование признаков (`StandardScaler`).
- Для основной части экспериментов данные разделены на обучающую, валидационную и тестовую выборки.

## Модели и методы

- **Линейные модели:** Linear Regression, Ridge, Lasso.
- **Деревья и ансамбли:** Decision Tree, Random Forest.
- **Градиентный бустинг:** CatBoost, LightGBM, XGBoost.
- Подбор гиперпараметров, в том числе с помощью `GridSearchCV` для деревьев и случайного леса.
- Использование `early stopping` при обучении моделей градиентного бустинга.
- Сравнение качества по **MAE, RMSE и MAPE**; визуализация результатов и анализ важности признаков для деревьев.

## Результаты

По результатам экспериментов в ноутбуке лучший **RMSE на тестовой выборке** среди моделей градиентного бустинга показал **LightGBM с early stopping**:

| Метрика | Результат |
|---|---:|
| RMSE | ≈ 7,93 млн ₽ |
| MAPE | ≈ 9,9% |

Для сравнения, базовая линейная регрессия дала RMSE около 19,3 млн ₽ и MAPE около 18%. Таким образом, нелинейные ансамблевые модели существенно улучшили качество прогнозирования относительно базового решения.

Ошибки предсказаний заметнее для наиболее дорогих объектов недвижимости.

## Технологии

Python, pandas, NumPy, scikit-learn, CatBoost, LightGBM, XGBoost, Matplotlib, Seaborn.
